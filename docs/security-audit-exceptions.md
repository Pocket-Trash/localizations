# Security audit policy

There are no active security audit exceptions. All high and critical findings,
invalid audit reports and registry failures block builds and publication.
Moderate findings retain the existing non-blocking policy.

The expired braces exception (ENG-366) was removed after
[GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)
was withdrawn on October 23, 2026 at 12:53:02 UTC.
