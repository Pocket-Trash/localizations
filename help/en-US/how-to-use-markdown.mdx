Markdown adds simple formatting to product, collection, and collection-item descriptions.

Fenced code blocks in this guide let trusted help content show source examples. They are not accepted in user-editable Markdown fields. Use only the formatting shown below in those fields.

## Headings

```markdown
# Main heading
```

# Main heading

```markdown
## Section heading
```

## Section heading

```markdown
### Subsection heading
```

## Text formatting

```markdown
**Bold text**
```

**Bold text**

```markdown
*Italic text*
```

*Italic text*

```markdown
***Bold and italic text***
```

***Bold and italic text***

```markdown

```

~~Strikethrough text~~

## Links

Relative links open another Pocket Trash page in the same tab.

```markdown
[Open the image guide](/help/image-size-and-resolution-guide)
```

[Open the image guide](/help/image-size-and-resolution-guide)

HTTP and HTTPS links open an external website in a new tab.

```markdown
[Visit Pocket Trash](https://pocket-trash.app)
```

[Visit Pocket Trash](https://pocket-trash.app)

## Tables

Use a header row and a separator row. This example has three columns.

```markdown
| Item | Material | Finish |
| --- | --- | --- |
| Pen | Titanium | Stonewashed |
| Notebook | Paper | Natural |
```
